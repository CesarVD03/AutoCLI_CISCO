# AutoCLI CISCO

AutoCLI CISCO es una herramienta de terminal escrita en Python que ayuda a generar configuraciones para dispositivos Cisco de forma rápida y sencilla.

## ¿Qué hace?

La aplicación permite:

1. Seleccionar o indicar los parámetros necesarios.
2. Generar automáticamente los comandos CLI de Cisco.
3. Copiar los comandos generados.
4. Pegarlos directamente en la configuración del dispositivo.

## Características

- Generación rápida de comandos Cisco.
- Interfaz mediante terminal.
- Uso sencillo, sin necesidad de configurar manualmente cada comando.
- Implementado mediante programación con Python.
- Software libre.

## Requisitos

- Python 3
- Acceso al terminal o consola de tu sistema operativo
- Acceso al dispositivo Cisco que deseas configurar
